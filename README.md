# 睿创客服智能体平台

面向企业商品知识运营与智能客服场景的模块化智能体平台。系统将企业手册、图片和结构化资料转化为可版本化、可验证、可发布的知识，并通过客服接口与 WorkBuddy / Codex 等成熟智能体工具协同使用。

## 核心能力

- 企业知识生命周期：暂存、解析、切块、索引、质量门禁、发布与回滚
- 混合检索与回答：关键词检索、向量检索、重排、证据引用与低置信度保护
- 图文知识处理：保留手册图片与文本的关联，支持图片证据引用
- 多租户控制台：租户、知识空间、版本和访问令牌管理
- 智能体工具接入：通过工具接口让 WorkBuddy / Codex 用自然语言编排知识运营流程
- 比赛兼容模式：保留面向既有评测数据与接口的兼容能力

## 目录概览

- `work/customer_service_core/`：客服问答核心流程
- `work/knowledge_lifecycle/`：知识入库、切块、检索、发布和回滚
- `work/cloud_control/`：企业控制台、多租户与版本管理
- `work/customer_service_tools/`：面向智能体工具的能力接口
- `integrations/workbuddy/`：WorkBuddy 接入配置与说明
- `deploy/phase3c-production/`：生产部署脚本和基础设施配置
- `tests/`、`work/tests_phase2/`、`work/tests_phase3/`：自动化测试
- `docs/`：架构决策、验收门禁和运维文档

## 安全说明

仓库只保留源码、示例配置与必要的演示资料，不包含运行环境中的密钥、令牌、数据库、知识库索引、日志、备份或模型文件。配置请从 `.env.example` 创建，并在本地或部署环境中注入真实凭据。

## 项目状态

当前版本用于比赛评测、答辩演示和后续工程化迭代，尚未声明为通用商业发行版。具体阶段说明请参阅 `README_PHASE1.md`、`README_PHASE2.md`、`README_PHASE3.md` 与 `docs/`。

## 生产数据复现

私有仓库包含经完整性校验的生产数据逻辑快照，覆盖 PostgreSQL、多版本知识对象、托管知识库和比赛 RAG 索引。快照不含任何明文密码、Token 或私钥。数据范围、校验值和恢复步骤见 `reproduction/README.md`。
