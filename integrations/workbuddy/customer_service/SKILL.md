# 睿创多模态客服 Skill

## 适用范围

用于产品手册问答、售后政策问答，以及带产品图片的客服问题。

## 实时调用规则

1. 普通客服问题只调用一次 `answer_customer_question`。
2. 把用户原始问题放入 `question`，附件原样放入 `attachments`。
3. 不要先调用检索、图片识别或验证工具再回答。
4. 工具返回后，直接展示 `data.answer`；不得再次改写、总结、翻译或补充事实。
5. `data.images` 与答案中的 `<PIC>` 按原顺序展示；企业知识图片使用对应的 `data.image_refs[].url`。
6. `escalation_required=true` 时，保留工具原答并提示转人工，不自行猜测。

## 延迟原则

WorkBuddy 只承担入口与展示。路由、检索、多模态处理、生成和校验均由客服核心一次完成。

## 管理任务

实时 Skill 不暴露知识库写入、发布和回滚工具。管理员应使用单独的受控管理端或管理 MCP 配置。
